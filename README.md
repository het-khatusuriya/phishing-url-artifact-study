# Malicious URL Detection — Artifact-Aware Evaluation

This repository started as a course project (lexical features, a logistic-regression / random-forest / XGBoost soft-vote ensemble, SHAP, a Flask demo). Branch `research-v2` turns it into a reproducible research study of **how much of the reported performance of lexical URL detectors comes from dataset collection artifacts**, and what an artifact-aware training and evaluation protocol changes.

The original code is preserved unchanged on `main` and in `src/{data,features,models,evaluation,explainability}` and `notebooks/`. New code lives in `src/urlresearch/`, `scripts/`, `configs/` and `tests/`.

> The predictor and demo return **model estimates**. A URL that is not flagged is not thereby safe.

The original project file `data/raw/raw_data.csv` (253,098 URLs) is **not available**; its provenance analysis is in `research/DATASET_AUDIT.md` §1. If you have it, uncomment the `main` entry in `configs/datasets.yaml` and run every config with `dataset: main`.

Place downloads as described in `DATASET_SOURCES.md`, then:

```bash
python scripts/prepare_external.py                       # -> data/interim/*.csv (url,label[,timestamp])

```

## Experiments

```bash
python scripts/generate_configs.py                       # writes configs/matrix/*.yaml and RUN_ORDER.txt
python scripts/run_all.py                                # main matrix (resumable; skips completed runs)
set RUN_ORDER_FILE=RUN_ORDER_LOCO.txt  && python scripts/run_all.py   # leave-one-corpus-out
set RUN_ORDER_FILE=RUN_ORDER_CANON.txt && python scripts/run_all.py   # canonicalised features
python scripts/run_experiment.py configs/matrix/A_v2_grouped.yaml     # any single run
python scripts/reproduce_original_pipeline.py --dataset phiusiil      # original notebooks' code path
```

Each run writes `results/runs/<run_id>/` with `config.json`, `environment.json`, `split_<seed>.json` (indices + class balance + domain-overlap report), `predictions_<model>_<seed>[_ext_<set>].csv`, `metrics.csv`, `resources.csv` and `run.log`. Full matrix run time on the test machine: roughly one working day.

## Protocol in one paragraph

Malicious = 1. Duplicates are removed after light normalisation and URLs with conflicting labels are dropped. The main split groups by registered domain (no domain in two partitions). Thresholds (max-F1, FPR ≤ 1 %, FPR ≤ 0.1 %) are chosen on validation only and applied unchanged to test and external sets. Five seeds for tabular models, three for char models (one for corpus B). Paired bootstrap and McNemar tests compare models on identical test URLs. Details: `research/EXPERIMENT_PROTOCOL.md`.

## Demo app

```bash
python scripts/train_final_model.py --dataset phiusiil --feature-set lexical_v2_canon --model xgb --split grouped
set URL_MODEL_BUNDLE=models\xgb_lexical_v2_canon_grouped_s42.joblib && python app.py
```

`POST /api/predict {"url": "...", "policy": "val_fpr0.01"}` returns the probability, threshold, a flag, a confidence band and an explicit non-guarantee statement.

## Limitations

See `paper/manuscript.md` §8 and `research/RESEARCH_GAPS.md`. In short: the original dataset is unavailable; all corpora are public collections with their own artifacts; timestamped data are positive-only and mostly 2021–2026; no transformer baseline (CPU only); robustness is tested only for the listed label-preserving mutations.
